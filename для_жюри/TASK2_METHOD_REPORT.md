# Задача 2. Методологический отчёт: прогноз расходов и структурные сдвиги (СЗФО)

**Объект:** помесячные агрегаты расходов двух групп муниципалитетов СЗФО (Тип A / Тип B, по 140 МО)  
**Два уровня работы:** (A) прогноз на горизонтах 1 / 3 / 6 / 12 месяцев; (B) поиск дат структурных сдвигов (changepoints) в динамике структуры трат  
**Репозиторий:** https://github.com/odisseykingitaki-commits/sber-szfo-forecast  

Числа сверены с `results/forecast_all_models.csv`, `forecast_foundation.csv`, `forecast_news.csv`, `changepoints_consensus.csv` (канон после исправления утечки будущего).

## Краткий словарь

| Сокращение | Расшифровка |
|------------|-------------|
| **МО** | муниципальное образование |
| **СЗФО** | Северо-Западный федеральный округ |

| **PLM** | Pairwise Linear Model — матрица условных зависимостей между долями категорий расходов |

| **PR₊** | Participation Ratio положительной части спектра — насколько «собрана» структура |
| **Frustration** | доля отрицательных собственных значений (мера конфликтности связей) |
| **LGBM** | LightGBM — градиентный бустинг на решающих деревьях |
| **GDELT** | Global Database of Events, Language and Tone — глобальная база событийных новостей |

| **ds** | дата (месяц) точки прогноза в ряде |
| **end_dt** | дата конца скользящего окна, из которого считаются спектральные признаки |
| **CP** | changepoint — дата предполагаемого структурного сдвига |
| **ARI** | Adjusted Rand Index — согласие разбиений соседних окон (для одного из детекторов сдвигов) |

В тексте ниже предпочтительно читаемые формулировки; сокращения — только после первой расшифровки или из словаря выше.

---

## 1. Какая задача решается

Есть помесячные расходы СберИндекса («Все категории») по **280 муниципалитетам СЗФО** за **≈24 месяца** (2023–2024). Нужно:

1. **Предсказать** средний расход по каждой из двух групп муниципалитетов на 1, 3, 6 и 12 месяцев вперёд и честно сравнить модели.  
2. **Найти даты**, когда меняется режим структуры трат (не только уровень ряда, а спектральный сигнал зависимостей между категориями).

Это два связанных, но разных вопроса: «какое число будет завтра» и «когда режим потребления переломился».

---

## 2. Как устроены две группы (Тип A / Тип B)

По признакам структуры расходов строится PLM (матрица условных зависимостей категорий) → берётся проекция на главную моду `U₁` → муниципалитеты делятся **медианой** на две равные группы по 140.

- **Тип A (сельский паттерн, cluster 0):** выше доля grocery.  
- **Тип B (городской паттерн, cluster 1):** выше доли food и transport.

Ярлыки — интерпретация структуры трат, **не** юридический статус МО. Дальше прогноз и поиск сдвигов ведутся по **двум агрегированным рядам** (средний расход в группе).

---

## 3. Пайплайн по шагам

### Шаг 1. Спектральные признаки динамики

На скользящих окнах (обычно 6 месяцев, шаг 1 месяц) по структуре трат считаются λ₁…λ₅, PR₊ и Frustration. Получается короткий «спектральный» временной ряд, описывающий, как меняется связность категорий.

### Шаг 2. Прогноз расходов (уровень A)

Для каждого типа (A/B) и каждого горизонта H:

1. Берём агрегат «Все категории» по группе.  
2. Holdout = последние H месяцев; остальное — обучение.  
3. Сравниваем модели: naive, seasonal naive, среднее, Prophet, LightGBM, CatBoost; варианты ML с Google Trends.  
4. Метрика — **MAE** на holdout. Победитель ячейки = модель с минимальным MAE среди доступных.

Опциональные признаки для ML: лаги, скользящие средние, спектральные величины, Trends.

### Шаг 3. Правило без утечки будущего

Спектральное окно попадает в признаки месяца `ds` **только если окно уже полностью завершилось до этой даты**:

`end_dt < ds`

(раньше ошибочно допускалось `start_dt ≤ ds` — окно могло «видеть» текущий/будущий месяц). После исправления вклад спектральных признаков в MAE стал скромнее — ожидаемо. Все цифры ниже — после этого фикса.

### Шаг 4. Foundation и внешние сигналы (доп. проверки)

- **Chronos** (`amazon/chronos-bolt-tiny`, zero-shot) — тот же holdout.  
- **Google Trends** (среднее по 11 субъектам СЗФО → один ряд на оба типа).  
- **GDELT** (Russia-wide событийный прокси). Локальный news NLP по СЗФО не делался.

### Шаг 5. Структурные сдвиги (уровень B)

На сигнале **`[λ₁…λ₅, PR₊]`** (без Frustration) запускаются 9 детекторов (семейство ruptures + CUSUM по ARI соседних окон). Дата сдвига = конец окна. **Консенсус:** дата отмечается, если её нашли ≥50% методов (≥5 из 9).

## 5. Результаты прогноза (exact MAE)

### Тип A — сельские

| H | naive | seasonal | prophet | LightGBM | winner |
|--:|------:|---------:|--------:|---------:|--------|
| 1 | 5197.90 | **4314.35** | 4375.11 | 5222.82 | **seasonal** |
| 3 | 3133.21 | 3862.03 | 1838.56 | **1761.44** | **LightGBM** |
| 6 | **1496.77** | 3663.17 | 1618.03 | 1649.22 | **naive** |
| 12 | 1888.81 | 2997.43 | **1514.08** | — | **prophet** |

### Тип B — городские

| H | naive | seasonal | prophet | LightGBM | winner |
|--:|------:|---------:|--------:|---------:|--------|
| 1 | 7222.19 | 7282.87 | **5641.67** | 8478.98 | **prophet** |
| 3 | 4713.06 | 6386.06 | **2653.36** | 5240.56 | **prophet** |
| 6 | 2168.01 | 6415.53 | **2039.51** | 2782.76 | **prophet** |
| 12 | **2525.30** | 6608.86 | 3415.60 | — | **naive** |

**Итог:** единого победителя нет. Prophet часто лучше на городских; LightGBM — на сельских при H = 3; naive конкурентоспособен. Google Trends **не** стабильно помогают. При H = 12 у LightGBM/CatBoost пустые ячейки (мало точек после lag_12).
